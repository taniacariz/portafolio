## Proyectos destacados

1. **[Vue Product Showcase](https://taniacariz.github.io/Vue-Product-Showcase/)** (Caso de estudio principal)  
   Catálogo digital interactivo desarrollado con Vue 3, estado global con Vuex 4, consumo de REST API con Axios y pruebas automatizadas con Jest y Cypress.  
   [Repositorio en GitHub](https://github.com/taniacariz/Vue-Product-Showcase)

2. **[BookList SPA](https://taniacariz.github.io/BookList-SPA/)**  
   Single Page Application con Vue 3, Composition API, Vue Router 4 y almacenamiento en LocalStorage.  
   [Repositorio en GitHub](https://github.com/taniacariz/BookList-SPA)

3. **[Alke Wallet](https://taniacariz.github.io/alke-wallet/)**  
   Simulador de billetera digital con JavaScript ES6+, Bootstrap y LocalStorage.  
   [Repositorio en GitHub](https://github.com/taniacariz/alke-wallet)

4. **[SmartBudget](https://taniacariz.github.io/SmartBudget/)**  
   Aplicación de presupuesto personal con Sass, arquitectura BEM y JavaScript.  
   [Repositorio en GitHub](https://github.com/taniacariz/SmartBudget)

5. **[TaskFlow](https://taniacariz.github.io/TaskFlow/)**  
   Gestor de tareas orientado a objetos (POO) con consumo de API REST externa.  
   [Repositorio en GitHub](https://github.com/taniacariz/TaskFlow)

6. **[Aplicación Consola](https://taniacariz.github.io/AplicacionConsola/)**  
   Emulador interactivo de terminal web desarrollado con JavaScript Vanilla.  
   [Repositorio en GitHub](https://github.com/taniacariz/AplicacionConsola)
